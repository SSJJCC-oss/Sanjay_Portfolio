Key Features

  • Real-time person detection (YOLOv8) and pose estimation (MediaPipe) for activity recognition
  • Fall detection logic optimised for on-device inference
  • Runs fully on a Raspberry Pi 5 with a Pi camera (picamera2)
  • Biometric patient calibration, so the system recognises the monitored person from body proportions
  • Automated health reports, generated on a schedule
  • Live caregiver dashboard, served securely through Cloudflare Tunnel

My Contribution

  • Integrated the module into the backend routes and the caregiver dashboard.
  • Automated health-report generation with a scheduled cron job.

WhatsApp AI Ordering Agent

An AI ordering assistant that lets customers order food from a local takeaway just by messaging its WhatsApp number. An AI agent understands the message, checks the live menu and stock, takes the delivery address and payment method, and records the order. Staff manage everything from a simple mobile app, and customers get automatic WhatsApp updates as their order progresses. It gives small restaurants their own commission-free ordering channel alongside the delivery apps.

Key Features

  • Natural-language ordering over WhatsApp, powered by a Google ADK agent running Gemini through Vertex AI
  • Live menu and stock checks, so the agent only offers what’s actually available
  • Customer registration, saved addresses, and location sharing via WhatsApp
  • Payment method choice (cash, card, Revolut or bank transfer), configurable per restaurant, with exact payment instructions generated by code
  • Automatic WhatsApp updates when staff change an order’s status (“Preparing”, “Out for delivery”, “5 minutes away”)
  • Card payment links sent to the customer automatically once staff add them
  • “Where’s my order?” answered from live order data, never guessed
  • Special-offer broadcasts to opted-in customers
  • Staff app built in AppSheet on top of Google Sheets, with no technical knowledge needed

My Contribution

  • Designed and built the order status notification engine: a scheduled poller that detects status changes and sends WhatsApp updates, with duplicate prevention and automatic retries.
  • Built the payment module (payments.py): per-restaurant payment methods, validation in code (not by the model), and exact payment instructions using the order ID as the reference.
  • Added the get_order_status agent tool, so customers can ask about their order and get answers only from real data.
  • Made the agent configurable per restaurant (name and payment methods through environment variables), so one codebase can serve multiple restaurants.
  • Extended the Google Sheets data model and AppSheet staff app (status buttons, payment fields, read-only tracking columns).
  • Set up local testing through Vertex AI with least-privilege IAM access, wrote local test scripts, and deployed to Cloud Run with a tested, zero-downtime rollout and Cloud Scheduler jobs secured by a secret header.

Technologies Used

Python · Google ADK · Gemini (Vertex AI) · FastAPI · Twilio WhatsApp API · Google Sheets API · AppSheet · Firestore · Google Cloud Run · Cloud Scheduler · Secret Manager · Docker

Status

Deployed on Google Cloud Run. Preparing a pilot with a local takeaway in Limerick.

Credit & Collections Copilot

A multi-agent AI copilot for UAE wholesale distributors that sell to shops on credit. It sits beside the company’s existing billing system, reads its data safely, and helps office staff and managers chase overdue payments, approve new orders and understand their numbers, in plain English. The AI never touches the data directly: Python does the maths, and the AI explains it.

Key Features

  • Daily credit and collections briefing: total owed, overdue amounts by age (0–30, 31–60, 61–90, 90+ days), shops to chase first, and shops over their credit limit
  • Order approval assistant that recommends APPROVE, REVIEW or HOLD for each new order, with plain-English reasons
  • Payment reminder drafts in English and Arabic, using real invoice numbers and amounts and queued for human approval (never sent automatically)
  • “Ask your data”: managers ask questions such as “Which shops in Sharjah are more than 60 days overdue?” and get answers from safe, read-only queries
  • “Shops going quiet”: detects regular customers whose ordering has stopped compared with their usual rhythm
  • Multi-agent design: a router agent hands each request to specialist agents (briefing, credit, collections, data Q&A)

My Contribution

  • Analysed a two-year demo database (~300 shops, ~27,000 orders) to map the business flow from order to payment, and documented every assumption.
  • Built a seed script that adds realistic UAE test data: orders with known correct decisions, tax registration numbers (TRN), Arabic/English language preferences and post-dated cheques.
  • Designed and wrote the rules engine: overdue ageing, a weighted “who to chase first” priority score, explainable credit decisions, and quiet-shop detection based on each shop’s own ordering rhythm.
  • Built a SQL safety guard that allows only single read-only queries on allow-listed tables and columns, enforced inside the database by SQLite’s authorizer.
  • Wrote a pytest suite that checks every rule against known answers, with no API key needed.

Technologies Used

Python · Google ADK · Gemini · Multi-Agent AI · FastAPI · SQLite · pytest · HTML / CSS / JavaScript
